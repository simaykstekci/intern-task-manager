# Intern Task Manager

A full-stack task management application designed to help interns organize their tasks, track progress, and manage their daily workflow through a simple and structured interface.

## 🚀 Overview

Intern Task Manager is a full-stack web application developed as a practical software engineering project. The application focuses on task creation, organization, status management, and progress tracking.

The project was developed with a focus on **clean architecture, type safety, API design, database integration, validation, testing, and maintainable code structure**.

## ✨ Features

* Create, update, and delete tasks
* Track task status and progress
* Organize internship-related tasks
* RESTful API architecture
* Input validation
* Database persistence
* Responsive user interface
* Error handling
* Automated tests
* Type-safe development

## 🏗️ Architecture

The project follows a separated frontend/backend architecture:

```text
intern-task-manager/
├── frontend/
│   ├── components/
│   ├── pages/
│   └── ...
│
├── backend/
│   ├── routes/
│   ├── controllers/
│   ├── services/
│   ├── schemas/
│   └── ...
│
├── prisma/
│   └── schema.prisma
│
└── README.md
```

The application separates UI, API, business logic, validation, and database responsibilities to keep the codebase easier to maintain and extend.
